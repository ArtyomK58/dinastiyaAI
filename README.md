# NORTHSTAR

Учебная игра о финансовых рынках. Исходный код прототипа v9 со светлым дизайном.

## Запуск

Откройте `index.html` в браузере или запустите `python -m http.server 8000` из корня проекта и перейдите на `http://localhost:8000`. Установка зависимостей не нужна.

## Структура

- `index.html` — разметка четырёх режимов и интерфейс Лео.
- `css/styles.css` — оформление и анимации.
- `js/app.js` — сценарии, симуляция рынка, сделки, достижения, уроки и демонстрационный чат.
- `docs/` — исходные материалы концепции NORTHSTAR.
- `.github/workflows/pages.yml` — публикация сайта через GitHub Pages.

## GitHub

Создайте пустой репозиторий и загрузите содержимое этой папки в его корень. Для публикации выберите Settings → Pages → Source → GitHub Actions.

## Ограничения

Это клиентский прототип: котировки вымышлены, Лео использует демонстрационные правила, сервер и API настоящей AI-модели отсутствуют. Часть состояния сохраняется локально в браузере. Документы концепции не означают, что все описанные функции реализованы. Перед публичной публикацией проверьте содержимое docs.
