# NORTHSTAR v14

Учебная игра «Первый миллион». В проекте есть иллюстрированный пролог, сюжет с биржей Лиоры и Лео, практика с лентой «Бык в курсе» и Академия. В этой версии прогресс действует до перезагрузки страницы.

## Запуск

Открой `index.html` в браузере. Все файлы сайта находятся в архиве. Установка и сборка не нужны.

## Публикация на GitHub Pages

1. Распакуй архив и добавь его содержимое в корень репозитория. На одном уровне должны лежать `index.html`, `README.md` и папки `assets`, `css`, `js`.
2. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку, куда загрузила файлы (обычно `main`), и папку **/ (root)**. Нажми **Save**.
4. После публикации ссылка на сайт появится в **Settings → Pages**.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Файлы сайта

- `index.html` — главная страница.
- `css/styles.css` — оформление и анимации.
- `js/market.js` — биржа Лиоры, торговый тренажёр и Лео.
- `js/content.js` — учебные главы, новости и пути к иллюстрациям.
- `js/campaign.js` — пролог, сюжет, действия и переходы между разделами.
- `assets/` — иллюстрации и персонажи.
